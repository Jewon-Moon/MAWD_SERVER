매장 문서 (MD) 실제 반영

AI가 고객에게 안내할 때 읽는 매장 맥락입니다. 템플릿으로 칸을 채우면 정해진 형식의 MD가 만들어지고, AI 프롬프트에 자신 있으면 직접 작성으로 MD를 쓰거나 파일을 올릴 수 있어요. 어느 쪽이든 환불 약속 금지 · 개인정보 보호 · 본인 확인 · 사장님 연결 같은 안전 규칙은 바뀌지 않습니다.

알림 실제

        

          시험 알림:
          
        

      

      
통화 · 채팅 중 감정 점수가 올라가거나 요약 카드가 생기면 알림이 옵니다. 우선순위 기준과 우선순위별 표시 방식(모달 · 배너 · 토스트 · 배지)은 매장 설정 → 알림의 priority · alert_styles에서 바꿉니다. 알림에는 고객 원문(욕설)을 싣지 않습니다.

푸시 알림 (FCM) 실제

        
      

      
화면을 안 보고 있을 때도 휴대폰 · 브라우저로 알림을 받습니다. 어떤 우선순위를 푸시로 보낼지는 매장 설정 → 알림 → push에서 정합니다 (기본: 긴급 · 높음, 조용한 시간에는 긴급만). 서버에 Firebase 설정이 있어야 동작하고, https(터널 주소) 또는 localhost에서만 권한을 요청할 수 있습니다.
