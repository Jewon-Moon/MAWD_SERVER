🛒 더미 커머스 스토어 (실시간 시연용)

연동 대상 확인 중… 연동 전
MAWD 콘솔 통화/채팅 데모

1. 실시간 주문 넣기

새 주문을 넣거나 상태를 바꾸면 MAWD AI가 실제 네이버/쿠팡 호환 API로 바로 읽어갑니다.

판매처
주문자 이름을 입력해 주세요.
연락처 4자리 이상을 입력해 주세요.
상품명을 입력해 주세요.
숫자 금액만 입력해 주세요.
또는 끄면 실시간 단건 조회(주문번호 말하기) 테스트 가능

2. 실시간 고객 문의 넣기 (AI 응대 테스트)

방금 넣은 주문으로 바로 문의를 보내면 MAWD AI가 주문·배송 상태를 읽고 답합니다.

고객명을 입력해 주세요.
본인 확인을 위해 주문번호와 연락처 뒷 4자리를 함께 적어 바로 테스트할 수도 있습니다.
문의 내용을 입력해 주세요.
대기
문의를 보내면 여기에 AI 답변이 실시간 표시됩니다.

3. 더미 커머스 주문 현황

상태 버튼을 누르면 즉시 상태가 바뀌고(필요 시 자동 동기화) MAWD AI가 바뀐 상태를 반영합니다.
